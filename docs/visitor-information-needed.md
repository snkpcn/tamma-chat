# ข้อมูลที่ต้องให้ทีมทำมา-ชาติยืนยัน

กรอกข้อเท็จจริงพร้อมผู้ยืนยัน/แหล่งข้อมูล วันที่ตรวจสอบ และวันเริ่ม–สิ้นสุดที่ใช้ได้ ไม่ต้องเดาคำตอบให้ครบทุกช่อง หากยังไม่ทราบให้ระบุว่าไม่ทราบ ข้อมูลด้านล่างยังไม่ได้ถูกรับรองจากการมีเมนูหรือชื่อกิจกรรมในระบบ

| ข้อคำถาม | ข้อมูลที่ต้องยืนยัน |
| --- | --- |
| 4 | ได้รับข้อมูลจากผู้ใช้แล้ว: คาเฟ่ จอดรถ สวน/บึงเข้าชมฟรี; ยังต้องยืนยันค่าบริการของโซนอื่นและกิจกรรมแยก |
| 6 | ได้รับข้อมูลจากผู้ใช้แล้ว: ลานจอดหน้าคาเฟ่ ช่องจอดผู้สูงอายุ/ผู้พิการใกล้ทางลาด และห้องน้ำสำหรับผู้ใช้วีลแชร์พร้อมราวจับ; ยังไม่มีจำนวนช่อง/ขนาดวัดจริง |
| 8 | ทางเข้าคาเฟ่และห้องน้ำมีข้อมูลจากผู้ใช้แล้ว; ยังต้องยืนยันเส้นทางสวน กิจกรรม ที่พัก ความกว้างจริง และบริการรถเข็นยืม/เช่า |
| 10 | ร้านตำมา-ชาติเปิดรับลูกค้าแล้วหรือยัง เวลาและวันหยุดของร้านอาหารโดยเฉพาะ |
| 11–13 | เมนูและราคาของจริง ระดับเผ็ดที่ยืนยันได้ วัตถุดิบ สารก่อภูมิแพ้ การปรับเมนู และการปนเปื้อนข้าม |
| 14 | กลุ่ม 15 คนต้องจองไหม จองล่วงหน้ากี่วัน ความจุโต๊ะ และวิธีจอง |
| 15,21 | กิจกรรมที่เปิดจริงแยกรายวัน รอบเล่น โซนที่ยังไม่เปิด และการหยุดตามสภาพอากาศ |
| 16 | ผู้ใช้ให้ราคาอ้างอิงขี่ม้า 90 นาที 500 บาท ซึ่งต่างจากชุดหลังบ้านจำลอง ต้องยืนยันแพ็กเกจปัจจุบันก่อนใช้จองจริง |
| 17 | เงื่อนไขมือใหม่ คนสอน/คนจูงม้ามีหรือไม่ และรวมอยู่ในราคาหรือคิดเพิ่ม |
| 18 | อายุ/ส่วนสูงขั้นต่ำของเด็ก เงื่อนไขการนั่ง ผู้ปกครอง และการประเมินหน้างาน |
| 19 | น้ำหนักสูงสุดของผู้เล่น เงื่อนไขที่ต่างตามม้า/รอบเล่น |
| 20 | ความจุเป็ดน้ำ น้ำหนักรวมที่อนุญาต เสื้อชูชีพ/ขนาดเด็ก และข้อจำกัด |
| 22 | ฝนตกเลื่อนได้ไหม คืนเงินกรณีใด ระยะเวลาแจ้งและขั้นตอน อ้างอิงตามรายการจองจริง |
| 23–24 | สถานะเปิดเฮือนสเตย์ ประเภทห้อง ราคา ความจุ และแหล่งข้อมูลห้องว่างจริงตามวันเข้า–ออก |
| 25 | แพ็กเกจที่มีจริง สิ่งที่รวม/ไม่รวม ราคา จำนวนคนและช่วงวันที่ใช้ได้ |
| 26–27 | สินค้าของจริง ราคา สต๊อก ชื่อผู้ผลิต ชุมชน จังหวัด และเรื่องราวพร้อมหลักฐานรายสินค้า |
| 28 | พื้นที่จัดส่ง ข้อจำกัดสินค้า บริษัทขนส่ง ค่าส่งตามน้ำหนัก/ปลายทาง ระยะเวลาและวิธีคำนวณ |

เวลา 06:00–18:00 น. ที่ผู้ใช้ให้เป็นเวลารวม/ข้อมูลอินทนิลตาดโตน ไม่ใช้ยืนยันว่าทุกร้านหรือทุกกิจกรรมเปิดเวลาเดียวกัน นโยบายน้องหมาครอบคลุม Outdoor/แคมป์ปิ้งของอินทนิลตาดโตนพร้อมเงื่อนไขที่ให้ไว้ ไม่ขยายไปถึงสัตว์ชนิดอื่น ที่พัก หรือทุกโซน

ได้รับรายการอาหาร ขนม และราคาเครื่องดื่มจากผู้ใช้แล้ว เก็บใน `_user-supplied-venue-facts.ts` เป็นแหล่งอ้างอิงแยกจากเมนูที่สั่งได้ ราคาที่มาจากเว็บรวม/สาขาอื่นยังไม่ถือเป็นราคาสาขาตาดโตน และเมนูรสอ่อนไม่ใช่หลักฐานว่าไม่มีสารก่อภูมิแพ้หรือเหมาะกับเด็กทุกคน
