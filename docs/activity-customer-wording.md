# Activity customer wording

Customer-facing Activity confirmations must avoid internal operations terms.

- Horse assignment label: `น้อง`
- ATV assignment label: `รถ`
- Archery assignment label: `ช่องยิง`
- Never show `ทรัพยากร` to customers for Activity assignments.

Staff/internal fallback commands may keep technical identifiers where needed; customer messages should remain natural Thai.
